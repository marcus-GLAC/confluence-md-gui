Bước 1 / 5

Kết nối Confluence

Nhập thông tin tài khoản Atlassian để ứng dụng đọc được các trang tài liệu.

Phần đầu của đường dẫn khi bạn mở Confluence, ví dụ https://congty.atlassian.net.

Tạo API token → Create API token → sao chép và dán vào đây.

Bước 2 / 5

Export tài liệu

Dán đường dẫn trang, folder hoặc space trên Confluence. Ứng dụng sẽ tự nhận biết loại nội dung.

Mở trang trên trình duyệt, sao chép địa chỉ trên thanh URL và dán vào đây.

Nên dùng đường dẫn ngắn. Lần export sau chỉ tải lại những trang có thay đổi.
