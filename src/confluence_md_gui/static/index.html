Confluence → Markdown

Export trang Confluence ra .md (kèm ảnh) và đẩy lên GitHub.

Quét các file .md trong thư mục kết quả để tìm ảnh sẽ không hiển thị trên GitHub.

    Chọn một file bên trái để xem.

    Chỉ file mới hoặc đã thay đổi được tải lên. File đã xoá ở máy sẽ không bị xoá trên GitHub.
